# 与你，慢慢 · 我们的回忆册

樱花浅粉色的双人回忆网站，支持照片、视频、聊天、短笺、纪念日和心动收藏。

访问：https://taffy.yongzhen666.top

## 云端存储

新增回忆通过同源 API 写入 Sites 配置的 Cloudflare 存储：D1 保存回忆文字、日期、昵称、纪念日和收藏；R2 保存照片、视频。页面显示从数据库核算的已保存媒体字节数、文件数量和连接状态。只有服务器确认成功后，网页才显示保存成功；连接失败时不会悄悄退回浏览器本地保存。

根据 [OpenAI 官方容量说明](https://help.openai.com/en/articles/20001339-creating-and-using-chatgpt-sites)，每个 Site 的 D1 数据库最多 10 GB，文件存储没有固定的单站容量上限，但仍受账号共享使用与存储限制约束。这不代表无限免费容量。平台没有提供账号剩余共享配额的查询接口；网页明确显示未知，而不虚构可用 GB 数字。单张照片最大 30 MiB，单个视频最大 1024 MiB（界面简称 MB）。视频通过 8 MiB 分片上传，支持进度显示、分片失败重试和取消；每次请求只读取一个分片，避免把整个 1 GiB 视频载入服务器内存。未完成上传的会话在最后一个分片成功后保留 24 小时，后续开始上传时清理过期会话。

云端保存后，在其他设备登录同一个获授权账号即可查看。站点当前保持所有者私有；他人需要由站点所有者在 Sites 分享设置中授权，不能仅凭链接访问。API 和媒体都由 Sites 的私有访问边界保护，R2 文件没有公开链接。请勿将此共享相册直接改成公开网站而不增加应用层权限控制。

## 原有本机回忆

旧版本 IndexedDB 和 localStorage 内容不会被清除。网页检测到本机旧回忆后提供「将本机回忆存到云端」按钮；明确点击后才迁移，原始本机副本保留。迁移和备份导入保留回忆 ID，失败后可安全重试，已保存的回忆不会重复创建。不能从网站源码或开发环境自动读取用户浏览器中的旧回忆。

页脚「导出回忆」会生成包含云端媒体文件的 JSON 备份。为避免浏览器内存溢出，媒体合计超过 90 MiB 时会明确停止 JSON 导出；较大视频请在回忆详情选择「下载原文件」单独备份，恢复时重新选择文件上传。JSON 导入文件仍限 150 MiB。可通过「导入备份」恢复到云端。导入是逐条操作；中途失败会显示已成功的数量，可使用相同备份重试。备份包含私人内容，请妥善保管。

初始照片、视频、聊天和日期均为明确标注的虚构示例。示例媒体包含在部署代码中，不计入用户上传媒体用量；用户上传的私人文件不会进入源码、GitHub 或发布归档。

## 开发与发布

前端源码位于 `dist/`，API 位于 `worker/api.js`，数据库 schema 位于 `db/schema.ts`，生成的不可变迁移位于 `drizzle/`。

```sh
npm ci
npm run db:local
npm run build
npm run dev
```

本地开发使用 `wrangler.local.jsonc` 的本地 D1/R2 数据，不操作生产资源。预览地址为 http://127.0.0.1:4173。修改前端或 Worker 后运行 `npm run build` 更新预览文件。

Sites 的 Vinext 模板关键构建文件在当前环境不可用，因此采用技能中提供的 Worker ESM 部署格式：将前端页面及必要示例媒体打包到一个独立 Worker，生成 `outputs/site/server/index.js`、`outputs/site/.openai/hosting.json` 和 `outputs/site/drizzle/`。发布目录 `outputs/` 不进版本库。`.openai/hosting.json` 保留原 Site 项目标识并声明 DB/BUCKET；发布由 Sites 提供资源绑定和迁移。

所有服务凭据只通过会话内存及标准输入传递，不提交或写入配置文件。

## 验证

`npm test` 使用真实 Miniflare D1/R2，在隔离临时目录测试 PNG/MP4 保存与读取、视频 Range、跨 Worker 重启持久性、并发迁移去重、用量统计、设置与收藏、上传限制、跨站写入保护和删除清理。测试使用的本地 workerd 套接字需要执行环境允许本地网络。

浏览器验证覆盖桌面/手机排版、新增云端回忆、独立浏览器读取、旧版迁移原件保留、备份恢复和错误状态。生产发布后另行检查实际绑定、媒体写入读取和清理。
