# 与你，慢慢 · 我们的回忆册

一个以樱花浅粉色、奶油白和相纸质感为主题的双人回忆网站。纯 HTML、CSS、JavaScript，无需安装依赖。

## 访问与预览

部署地址：https://taffy-our-little-days.wyzhen5.chatgpt.site

Sites 初始访问权限为站点所有者私有。网站访问权限由 Sites 管理；本项目没有把前端密码当作访问控制。

本地预览：

```sh
python3 -m http.server 4173 --directory dist
```

打开 `http://localhost:4173`。请使用 HTTP 服务而非直接双击 HTML，以便浏览器的本地存储与媒体功能正常工作。

## 已有功能

- 响应式照片相册、视频播放、聊天与短笺展示。
- 分类筛选、搜索、心动收藏、回忆详情与键盘切换。
- 添加照片、视频、文字和聊天记录；单个媒体文件最大 30 MB。
- 自定义名字与相恋日期，以北京时间计算在一起的天数。
- 将回忆导出为包含媒体的 JSON 备份，并在其他浏览器导入恢复。
- 原生弹窗、键盘操作与减少动画偏好支持。

## 内容与存储

初始照片为生成的虚构示例，文字和日期为示例内容，页面明确标注。示例视频由示例主图制作而成。`dist/assets/road.png` 作为备用示例照片保留，无需署名。

用户添加的回忆和媒体只保存在当前浏览器的 IndexedDB，昵称、纪念日和喜欢保存在 localStorage。当前版本没有服务端上传、两人共享或跨设备自动同步。清除浏览器数据会删除本地回忆，请定期从页脚导出备份。导出文件包含个人照片、视频和文字，应自行妥善保管。

站点发布不会上传浏览器内添加的私人资料，也不会把这些资料提交到 GitHub。若要让两个人在不同设备实时共享，需要后续加入身份认证与持久化的服务端存储。

## 项目结构

`dist/index.html` 为页面结构，`dist/styles.css` 为樱花粉主题与适配样式，`dist/app.js` 为交互和本地存储，`dist/assets/` 为示例媒体。`.openai/hosting.json` 保存 Sites 项目标识和静态发布目录。

## 验证

使用 Chromium / Playwright 验证桌面与手机排版、导航、照片详情、筛选收藏、新增文字和照片刷新后保留、纪念日保存；JavaScript 通过语法检查。浏览器测试使用隔离的临时上下文，测试数据不包含在部署源码中。
